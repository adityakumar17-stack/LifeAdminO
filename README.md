# FitPulse - Fitness Tracker SaaS

A modern fitness tracking SaaS application built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Dashboard** — Daily stats, activity rings, and quick actions
- **Workouts** — Log and track workouts with exercise details
- **Nutrition** — Track meals, calories, and macros
- **Progress** — Charts and analytics for weight, steps, and goals
- **Goals** — Set and monitor fitness targets
- **Profile & Settings** — Customize your experience

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Recharts
- Lucide React icons
- Local storage for demo data persistence
